# Pastel for Mac

A native clipboard manager, saved-link library, and Front Page for your projects.

**[Visit the website](https://pastel-for-mac.tisho.chatgpt.site)** · **[Download the latest release](https://github.com/tvidenov/Pastel-releases/releases/latest)**

Requires macOS 26 or later. Universal build for Apple silicon and Intel Macs.

This public repository hosts signed and notarized installers, release notes, and the Sparkle update feed (`appcast.xml`). App source is maintained in a private repository.
