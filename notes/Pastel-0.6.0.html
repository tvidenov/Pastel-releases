Your links, projects, and clipboard in one place

  • A Front Page for each space puts pinned bookmarks and every project link within reach. Projects use a compact layout, with clearer sections and equal-size pinned cards.
  • Pin a bookmark to the Front Page from the ribbon, search, or the page itself.
  • The optional Chrome companion brings your Front Page to every new tab. Pins and saved links stay connected to Pastel on this Mac. Set it up in Settings › Browser; the extension is installed locally using Chrome's Load unpacked option.
  • Find bookmarks through the compact Search action or the / shortcut. Activity and library health stay out of the way until you need them.

A closer look

  • Press Space in the ribbon for a much larger preview. Resize it or use Expand to fill the available screen.
  • Zoom into images, switch to 100% or Fit, and use a trackpad pinch to inspect details.
  • Adjust text size, wrap long lines, select passages, and read complete code snippets with syntax highlighting.
  • Copy, paste, edit, open, reveal files, or pin an item directly from its preview. Arrow keys browse; Space or Escape returns to the ribbon.
  • Preview PDFs and other documents with macOS Quick Look, and choose which file to view when a clip contains several files.
  • Detected sensitive items stay concealed in previews.

A more useful library

  • Organize pinboards and saved collections into spaces, and let a Focus filter select a space for you.
  • Saved links have an Inbox, Read Next, Done, collections, search, descriptions, and a Front Page. Import tabs and page details from Zen, or save the current tab from Safari, Chrome, or Zen.
  • Review stale links, pages that are no longer available, and tabs closed in Zen. Removal always stays under your control.
  • Share pinboards as .pastelpack files. Save and reuse Paste Stacks, or paste a pinboard in sequence.
  • Search across clipboard history and this space's pinboards, then narrow by item type, app, date, or source.

Privacy and fixes

  • Detected passwords and keys are excluded from MCP access, pinboard exports, and iCloud sync. MCP access is off on new installs until enabled.
  • The optional Claude organizer uses your own API key and only the saved-link metadata from the spaces you select; clipboard items are excluded.
  • Quick Start includes a practice paste, and can be reopened from the menu bar.
  • Improved sheet sizing, keyboard focus, VoiceOver labels, and pasting into Pastel's own windows.

Requires macOS 26 or later. Apple Intelligence features require a compatible Mac and enabled Apple Intelligence.
