Drag images anywhere

  • Image cards dragged out of the strip now drop into web pages and other apps.

Sync

  • Editing an item's text and then changing it back no longer deletes the item on your Macs.
  • Turning sync off stops a pass that is already running.
  • Setting up sync on a second Mac no longer duplicates spaces and pinboards that share a name, and a merged space keeps its Inbox.
  • A copy made after the same content was deleted on a Mac with a fast clock is kept.
  • Renames made on another Mac survive when that Mac's history expires.
  • Deleting synced items removes their previews and contents from iCloud Drive too.
  • A saved link deleted on one Mac is no longer saved again from an open tab on another.

Secrets

  • Text you create inside Pastel (New Text Item, Edit, Paste All, Shortcuts, Save Tab) is checked for credentials, the same as text you copy.
  • Shortcuts and Siri, the Library's list layout, Saved search and the Edit sheet no longer show a concealed item's text.
  • PGP private keys and encrypted private keys are recognised as secrets.
  • Clips a password manager marks as concealed are always concealed.
  • Import from Paste conceals credentials it brings in.

Paste Stack and pasting

  • Items you delete leave the Paste Stack instead of being pasted later.
  • Copying the same thing twice queues it twice.
  • Paste All keeps images in the stack and no longer pastes an empty item when nothing queued has text.
  • Direct paste works on keyboard layouts that move V, such as Dvorak.

Saved links and import

  • Deleting a saved link sticks while its tab is still open in a watched browser.
  • Moving a link to another collection keeps its state: hidden from the Desk, open counts, kept in Zen.
  • A page that fails to load because the network was down is no longer marked Not Found for good.
  • Page descriptions containing an apostrophe or a quote are no longer cut short.
  • Import from Paste no longer stops early on items it cannot read, and no longer removes your own clips that begin a longer one.
  • Import from Zen no longer adds the same page twice to one space.
  • Pinned, folder and Essential tabs in Zen are filed by the Zen import rather than dropped in the Inbox.

Vault export

  • Export no longer writes into a folder that already holds your own notes.
  • Files for items you have deleted are removed on the next export.
  • Weekly digests cover the week their name says.

Strip, Library and Pocket

  • Esc closes the preview when the search field is focused and nothing matches.
  • A search filter no longer stays on, unseen, after the strip closes.
  • The preview follows the selection after a click, a delete or a list switch.
  • Deleting a card in a search or a Smart Pinboard selects its neighbour.
  • Return, Esc, Tab and the arrow keys work while composing text with an input method.
  • The Library forgets a pinboard or collection from another space, or one you deleted.
  • The Front Page's Inbox count matches the Library's.
  • Closing the Library ends the Ask Pastel conversation.
  • A second click on a Pocket row while it closes no longer pastes twice.
  • Bare F1 to F12 can be recorded as shortcuts.
  • Quick Start asks before shortening how long history is kept.

Claude and other tools (MCP)

  • A long session no longer starts returning empty results.
  • Copying text with accents or emoji keeps them intact.
  • Searching with a short query keeps the kind filter.
