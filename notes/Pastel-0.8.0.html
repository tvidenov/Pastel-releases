# Pastel 0.8.0

  • Resize the clipboard ribbon by dragging its top edge up or down, or use the new size slider in Settings. Double-click the handle to return to the original size. Your choice is remembered.
  • At smaller sizes, choose Compact tiles for readable titles and details or Dock icons for thumbnails with details on hover. Switch from the ribbon’s More menu or Settings. Full preview cards return as you make the ribbon taller.
  • Keyboard selection, Quick Paste, dragging, context menus and Space preview work across ribbon sizes. Sensitive items stay concealed in both compact styles.
  • Sparkle now downloads signed updates automatically by default and installs them when you quit Pastel. Settings includes separate controls for automatic checks and downloads. Existing explicit update preferences are preserved.
