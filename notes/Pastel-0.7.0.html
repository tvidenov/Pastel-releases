# Pastel 0.7.0

## A Front Page for more browsers

  • Safari now includes Pastel Front Page as a bundled extension, with your pinned bookmarks, projects and saved links in new tabs and windows.
  • Firefox has a temporary extension preview, including a new-tab dashboard and optional home page. Permanent Firefox installation still requires Mozilla signing.
  • Browser settings guide you through Safari, Chrome and Firefox setup.

## Bring your open tabs together

  • Choose which browsers to collect normal open tabs from: Safari, Chrome, Firefox and Zen.
  • Matching links merge across browsers and profiles. Existing titles, lists, pins and Done status stay in place.
  • Browser sources appear on saved links. Closing a tab keeps its saved bookmark.
  • Only current tab titles and addresses are collected. Private tabs, browser history, page contents, internal pages and credential-bearing URLs are excluded. Automatically collected links skip background page fetching and organization.

Safari must be enabled in Safari’s Extensions settings. Existing Chrome installations need the updated extension files reloaded to grant the new tabs permission. Collection starts only after you opt in for each browser in Pastel’s Browser settings.
